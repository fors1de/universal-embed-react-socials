Thanks for helping improve `@fors1de/universal-embed-react-socials`.
## Reporting bugs
Open a [GitHub issue](https://github.com/fors1de/universal-embed-react-socials/issues) and include:
- Package version
- Web or React Native, and the platform (iOS, Android, or browser)
- The embed component and the post URL
- What you expected and what happened
Do not file security reports on the public issue tracker. Use [SECURITY.md](./SECURITY.md).
